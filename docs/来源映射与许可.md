## 2. 逐条映射

复用方式分四档，不混用：

- **原文复用** — 与来源逐字（中文）相同或仅作标点调整。
- **译写** — 来源是英文，按其语义写成中文。
- **方法吸收** — 采用其结构与工作步骤，措辞自撰。
- **自撰** — 依据合同（`prompt-enhancement-design` / 项目约定）新写。

许可列中 `S1 MIT ✔` 表示：该条款落在 1.5.6 分享包 `LICENSE` 明文覆盖的范围内（内嵌提示词模板），
其署名与许可全文已随包分发。
